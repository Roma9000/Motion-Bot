# 🎬 Motion Design Job Agent — Інструкція запуску

Агент моніторить **Upwork** і **Freelancehunt** по ключовим словам моушн-дизайну
і надсилає нові вакансії прямо в **Telegram**.

---

## Крок 1 — Створи Telegram-бота (2 хвилини)

1. Відкрий Telegram і знайди **@BotFather**
2. Напиши `/newbot`
3. Придумай назву, наприклад: `Motion Jobs`
4. Придумай username, наприклад: `motion_jobs_mybot`
5. BotFather надішле тобі **токен** виду: `123456789:AAHxxxxxxxxxxxxxxx`
6. Скопіюй цей токен — він потрібен у наступному кроці

---

## Крок 2 — Дізнайся свій Chat ID

1. Знайди бота **@userinfobot** у Telegram
2. Напиши йому будь-що
3. Він відповість твоїм **Chat ID** (число, наприклад `123456789`)

---

## Крок 3 — Налаштуй скрипт

Відкрий файл `agent.py` і заміни рядки на початку:

```python
TELEGRAM_BOT_TOKEN = "123456789:AAHxxxxxxxxxxxxxxx"   # ← твій токен
TELEGRAM_CHAT_ID   = "123456789"                       # ← твій chat_id
```

Також можна змінити інтервал перевірки (за замовчуванням 10 хвилин):
```python
CHECK_INTERVAL = 10 * 60   # 10 хвилин
```

---

## Крок 4 — Встанови Python і залежності

### Windows:
```bash
# Якщо Python не встановлений — завантаж з python.org
python --version

# Встанови бібліотеки
pip install -r requirements.txt
```

### Mac / Linux:
```bash
python3 --version
pip3 install -r requirements.txt
```

---

## Крок 5 — Запусти агента

### Windows:
```bash
python agent.py
```

### Mac / Linux:
```bash
python3 agent.py
```

Ти побачиш в консолі щось таке:

## Запуск у фоні (щоб не тримати термінал відкритим)

### Mac / Linux:
```bash
nohup python3 agent.py &
```

### Windows (через планувальник задач):
1. Відкрий "Планувальник завдань"
2. Створи нову задачу
3. Дія: запуск `python.exe` з аргументом шляху до `agent.py`

### Безкоштовний хмарний сервер (рекомендую для 24/7):
- **Railway.app** — безкоштовний план, легко деплоїти
- **Render.com** — теж безкоштовно для таких скриптів
- Просто завантаж папку і запусти

## Додавання нових ключових слів

У `agent.py` знайди розділ `KEYWORDS_EN` або `KEYWORDS_UK` і додай своє:

```python
KEYWORDS_EN = [
    "motion", "animation", "after effects",
    "твоє нове слово",   # ← додай сюди
    ...
]
```

## Питання / проблеми

- **Не приходять повідомлення?** — Перевір токен і chat_id, напиши `/start` своєму боту
- **Помилка feedparser?** — Запусти `pip install -r requirements.txt` ще раз
- **Upwork RSS не працює?** — Upwork іноді змінює URL, можна перевірити актуальний на upwork.com/ab/jobs/search
